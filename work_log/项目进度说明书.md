## 一、项目概述

### 1.1 项目定位
**小冶 (Xiaoye)** 是一个面向冶金工程研发人员的 **多智能体协作 AI 平台**。它通过"左屏阅读 PDF 文献 + 右屏 AI 协同对话"的沉浸式双核工位设计，为用户提供文献检索、图表分析、知识图谱查询、热力学计算等一站式冶金科研辅助能力。

### 1.2 核心设计哲学
项目架构深度参考 Anthropic Claude Code 的工程实践，提炼出四大核心理念：

| # | 设计理念 | 说明 |
|---|---------|------|
| 1 | **沉浸式双核人机工位** | 左屏 PDF 阅读 + 右屏 AI 对话，非传统"你问我答"阻塞流 |
| 2 | **极简分形隔离 (Fork/Swarm)** | 单主脑 Coordinator → 黑板 → 独立 Worker，禁止子 Agent 嵌套 |
| 3 | **环境启发式技能装填** | 运行时动态探测环境，按需加载工具，杜绝 Tool 泛滥导致幻觉 |
| 4 | **硬盘态外挂记忆闭环** | 三作用域 Markdown 记忆（global/project/session），替代短效 History |

### 1.3 技术栈

| 层级 | 技术选型 | 版本 |
|:---|:---|:---|
| 语言 | Python | 3.11 / 3.12 |
| Agent 框架 | LangGraph + LangChain | langgraph ≥ 0.2 |
| 向量数据库 | Elasticsearch (BM25 + Dense) | 8.12.x |
