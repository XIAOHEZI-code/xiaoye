## 一、完成工作

### 1. 推理管线 Claude Code 哲学吸收（核心重构）

**动机**: 原 Evaluator LLM 节点每轮额外5-10s判断"资料够不够"，多轮循环导致单问耗时120-180s。

**改动**: 完全删除 Evaluator 节点，吸收 Claude Code 的 Agent 循环哲学：

| Claude Code 模式 | 小冶映射 |
|:--|:--|
| 模型自主终止（text content 无 tool_use）| Researcher 无 tool_calls → 直达 Synthesizer |
| 衰减收益检测 | Compactor Jaccard 相似度 >50% → 注入停止信号 |
| Don't Gold-Plate | Researcher prompt: "你是决定何时停的人" |
| Effort 模型分级 | 快速(qwen-turbo) / 深度(qwen-max+thinking) |
| maxTurns 纯安全网 | MAX_REACT_LOOPS: 4→12 |

**效果**: 全链路5题测试 469.9s → 154.2s, **提速67%**，5/5通过。

**涉及文件**:
- `src/reasoning/graph.py` — 完全重写(449→395行): 删Evaluator, 加衰减检测, 模型分级, ClaudeCode prompt
- `src/delivery/chat_worker.py` — 深度/快速双分支 task_description + deep_mode 透传
- `src/api/chat_routes.py` — ChatRequest 加 deep_mode
